Why

These sources are published as a single current file that is replaced each day or month. The history — when a project appeared, when its operating date slipped, when it was quietly canceled — is lost unless someone captures every version. Queue Ledger does that, so you can answer "what did the source say on date X" with the exact file that was published, and see the change log in between. It is a leading indicator of generation and storage buildout.
